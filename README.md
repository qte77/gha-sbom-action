# gha-sbom-action

Keep SPDX SBOMs for your repository up to date automatically — one composite GitHub Action, two
sources (GitHub dependency graph + Syft), delivered as a reviewable PR.

## What

- Generates SPDX JSON SBOMs for your repository on every run, with no manual steps
- Combines two views: GitHub's dependency graph export and a Syft scan of the repository files
- Writes both files to one directory (`docs/SBOM` by default) so they live alongside your code
- Opens a pull request only when the SBOMs actually changed, or just reports the change
- Exposes `changed` and `pr_url` outputs for follow-up steps

## How

```yaml
permissions:
  contents: write
  pull-requests: write

jobs:
  sbom:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: qte77/gha-sbom-action@v0.1.1
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
```

Prerequisites, all inputs and outputs, and how the action works:
[docs/configuration.md](docs/configuration.md).

## Why

SBOMs are usually generated by hand or by a one-off CI step whose output is never committed, so the
inventory drifts from the code. This action regenerates SPDX documents from two independent sources
on a schedule and lands them as a reviewable PR, so the SBOM stays versioned next to the code.
